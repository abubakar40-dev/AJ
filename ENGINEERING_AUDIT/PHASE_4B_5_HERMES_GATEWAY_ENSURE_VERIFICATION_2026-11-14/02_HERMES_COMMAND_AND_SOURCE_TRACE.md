# 02 — Hermes Command and Source Trace (`gateway ensure`)

## Verified facts
- **Command exists (installed v0.23.0, source HEAD 2bd378ed1b8d):**
  - CLI registration: `hermes_cli/subcommands/gateway.py` adds subparser `ensure` with `ensure_json=True`, `--json` flag, `--timeout` (default `"60"`), sets `func=cmd_gateway_ensure` from `hermes_cli.gateway_runtime_cli`.
  - Help: `hermes gateway --help` lists `ensure` (“Ensure a local runtime without installing or replacing a service”); `hermes gateway ensure --help` states exit codes `0 ready; 2 invalid invocation; 3 incompatible; 4 authorization/profile mismatch; 5 deadline; 6 draining/update-paused; 7 inaccessible/conflicting supervisor. - **Execution path (source):**
  1. `hermes_cli/gateway_runtime_cli.py:cmd_gateway_ensure(args)` resolves `get_hermes_home()`, calls `ensure_gateway_runtime(get_hermes_home(), timeout=float(args.timeout))` under `redirect_stdout(sys.stderr)` (stdout reserved for protocol JSON). Builds payload from `dataclass asdict(result)`, adds sorted endpoint capabilities and `client_code_sha` (from `hermes_cli.version_info.get_code_identity()`), maps exit code via `ensure_exit_code(result)`, prints compact sorted JSON, raises `SystemExit(code)`. On `ValueError/TypeError` returns invalid invocation (exit 2).
  2. `hermes_cli/gateway_runtime.py:ensure_gateway_runtime(profile_home, *, timeout=DEFAULT_ENSURE_TIMEOUT=60.0, idle_exit=False)` is the core loop (discovery → verdict/start decisions → bounded wait). Uses `discover_gateway_endpoint`, `_served_by_multiplexer`/multiplex/start/service/replace helpers, update fence, ownership/discovery primitives.
  3. Start paths: `discover_existing_gateway_service` + `start_existing_gateway_service` (`gateway_runtime_service.py`) for installed/existing service backends (systemd/launchd/windows task/s6/no-supervisor cases) — **requests start once** (`start`/kickstart/bootstrap/run for configured existing service), does not install/rewrite units/plists as part of this function. If no existing service, `spawn_unmanaged_gateway` (`gateway_runtime_start.py`) spawns detached `sys.executable -m hermes_cli.main [selector] gateway run --quiet [--idle-exit] [--force]` with stripped/constructed env, logs to `<home>/logs/gateway-stdio.log`, platform-specific detach/job handling; explicitly `No --replace, persistence, login changes, elevation, shell, or inherited stdio` (per module docstring) and relies on runtime ownership fence.
  4. Replace path: only for incompatible older same-install owner (`runtime_protocol` mismatch upgrade case) via `_observe_replacing_stale` → `gateway_runtime_replace.replace_incompatible_owner` (planned-stop marker, SIGTERM/wait, guarded force kill) — **mutating/lifecycle intervention, conditional**.
