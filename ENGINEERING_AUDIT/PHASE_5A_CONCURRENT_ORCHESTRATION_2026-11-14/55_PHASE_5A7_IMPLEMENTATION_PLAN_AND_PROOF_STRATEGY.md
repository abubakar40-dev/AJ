## 10. Mandatory proof standard — no self-certification

Every requirement/invariant criterion must pass through distinct stages:

| Stage | Required activity | Evidence |
|---|---|---|
| **A. Implementation exists** | Relevant source change identified in correct location/intended path (traceable diff/refs) | Source refs, diff, requirement mapping |
| **B. Behavior is exercised** | Test or controlled execution invokes actual behavior (core logic not mocked away) | Test code/execution trace showing real path invoked |
| **C. Expected behavior is asserted** | Positive/negative outcomes checked; persisted state/relevant side effects inspected; forbidden states/transitions explicitly asserted absent | Assertions, state snapshots, logs/output |
| **D. Failure/adversarial behavior tested** | Malformed input, revoked authz, cancellation, races, interruption, ambiguity exercised; fail closed where required | Adversarial test cases/results/evidence |
| **E. Independent verification** | Separate pass reviews implementation vs Doc 54 and traceability matrix; inspects code, test bodies, output, persisted evidence; does not rely on implementer claims; re-runs relevant tests from clean documented invocation; independent test writing/review where feasible | Reviewer identity/notes, re-run commands/results, discrepancy log |
| **F. Regression verification** | Run focused tests, full suite; record exact commands, exit codes, pass/fail counts, warnings; investigate every failure (no hiding/relabeling) | Command log, outputs, failure investigations |
| **G. Evidence package** | Per verified criterion: Requirement ID, Test ID, file/name, exact command, source refs, observed vs expected, assertion evidence, output/log ref, verifier/verdict, limitations | Structured evidence record (see §12) |

**Status taxonomy (criterion-level):** `NOT STARTED` | `IMPLEMENTED — NOT VERIFIED` | `TESTED — PARTIAL` | `VERIFIED WITHIN DECLARED BOUNDARY` | `FAILED` | `BLOCKED` | `UNSUPPORTED`. Never use general “COMPLETE” to hide partial/unverified criteria.

**Rules:** passing tests ≠ proof of all invariants (criterion-by-criterion required). If test passes but does not exercise real behavior → `NOT VERIFIED`. If condition cannot be reproduced → `BLOCKED` or `UNSUPPORTED`, not `VERIFIED`.
